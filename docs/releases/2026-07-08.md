# 2026-07-08 版本说明

这是 SKYLOONG Flasher 的首个可用版本，面向 SKYLOONG/GK87 类 ESP32-S3 彩屏模块。

## 新增能力

- 新增 Wails + Go + React 桌面应用。
- 新增深色毛玻璃中文向导界面。
- 支持本地 zip、GitHub 仓库链接、GitHub 分支链接和 GitHub zip 链接。
- 自动下载 GitHub 压缩包，并显示实时下载进度。
- 自动解析 `flasher_args.json` 和 `flash_args`。
- 自动识别 ESP-IDF 源码包。
- 源码包没有构建产物时，支持在工具内自动准备 Git、ESP-IDF v5.1.4、Python、CMake、Ninja、交叉编译器、esptool 和构建依赖并继续构建。
- 运行时会优先复用本机、工具缓存或 exe 同级 `runtime` 离线包。
- 自动准备环境时，如果本机没有 Git，会下载 Git for Windows 的 MinGit 便携包并写入工具缓存，不修改系统 PATH。
- 便携 Git 下载源顺序为华为云镜像、npmmirror、GitHub，改善国内用户无法直连 GitHub 的情况。
- 自动准备环境时，EIM CLI 优先从乐鑫国内镜像下载，失败后切换国际镜像，最后才尝试 GitHub。
- ESP-IDF 安装过程内置 `IDF_GITHUB_ASSETS=dl.espressif.cn/github_assets` 和清华 PyPI 镜像，改善国内网络可用性。
- 支持 Windows PnP/COM 扫描。
- 区分 SKYLOONG 键盘运行态和 ESP32-S3 下载态。
- 生成并执行 esptool 刷机命令。
- 刷机、构建、下载、扫描都在界面内显示进度和日志。
- 高级日志从任务开始保留到最后，并同步写入 `%LOCALAPPDATA%\SkyloongFlasher\logs`，方便追溯问题。
- 工具启动时会主动准备 `downloads`、`packages`、`runtime`、`tools`、`cm`、`logs` 等工作文件夹；用户目录不可用时会退回系统临时目录。
- ESP-IDF 组件缓存会通过 `IDF_COMPONENT_CACHE_PATH` 指向 `%LOCALAPPDATA%\SkyloongFlasher\cm`，避免 Windows 默认组件缓存路径过深导致 `FileNotFoundError`。
- ESP-IDF 组件文件下载会通过 `IDF_COMPONENT_STORAGE_URL` 优先使用乐鑫国内组件文件源，再回退到国际源。
- 即使 EIM 包装进程返回成功，只要构建日志中出现 `CMake Error`、`cmake failed with exit code`、`FileNotFoundError` 等失败标记，工具也会按源码构建失败处理，避免误报“构建产物解析失败”。
- 隐藏 PowerShell、Python、idf.py、esptool 等子进程控制台窗口。

## 已验证

- `go test ./...`
- `npm run build`
- `wails build`

## 当前限制

- 首版主要面向 Windows 10/11 x64。
- 首次自动准备环境需要下载较多文件，网络较慢时请等待界面进度和高级日志。界面会显示当前下载源、下载进度、解压进度和失败切换提示。
- 离线完整版可以把 `runtime` 目录放在 exe 同级，供网络较差的用户直接使用。离线包建议包含 `runtime/tools/git`、`runtime/tools/eim.exe`、`runtime/eim-config` 和 `runtime/esp-idf`。
- 如果环境下载失败，普通用户只需要在工具里重试或改用离线完整版；不要要求用户自行安装 Git、Python 或 ESP-IDF。
- 如果构建命令结束但没有生成 `build` 文件夹，工具会给出中文提示，并要求查看高级日志前半段的真实构建错误。
- 如果旧版本已经在系统默认组件缓存中留下失败状态，更新后重新点击“准备环境并构建”，工具会使用新的短组件缓存目录重新拉取依赖。
- 不同批次键盘进入下载模式的方式可能不同，工具会给出引导，但仍需要用户按设备实际按键操作。

## 推荐固件包格式

```text
build/flasher_args.json
build/bootloader/bootloader.bin
build/partition_table/partition-table.bin
build/ota_data_initial.bin
build/GK87-Screen.bin
```

工具会递归扫描 zip，不要求这些文件一定在 zip 根目录。
