# 2026-07-08 版本说明

这是 SKYLOONG Flasher 的首个可用版本，面向 SKYLOONG/GK87 类 ESP32-S3 彩屏模块。

## 新增能力

- 新增 Wails + Go + React 桌面应用。
- 新增深色毛玻璃中文向导界面。
- 支持本地 zip、GitHub 仓库链接、GitHub 分支链接和 GitHub zip 链接。
- 自动下载 GitHub 压缩包，并显示实时下载进度。
- 自动解析 `flasher_args.json` 和 `flash_args`。
- 自动识别 ESP-IDF 源码包。
- 源码包没有构建产物时，支持在工具内自动准备 ESP-IDF v5.1.4 并构建。
- 运行时会优先复用本机、工具缓存或 exe 同级 `runtime` 离线包。
- 支持 Windows PnP/COM 扫描。
- 区分 SKYLOONG 键盘运行态和 ESP32-S3 下载态。
- 生成并执行 esptool 刷机命令。
- 刷机、构建、下载、扫描都在界面内显示进度和日志。
- 隐藏 PowerShell、Python、idf.py、esptool 等子进程控制台窗口。

## 已验证

- `go test ./...`
- `npm run build`
- `wails build`

## 当前限制

- 首版主要面向 Windows 10/11 x64。
- 首次自动准备 ESP-IDF 需要下载较多文件，网络较慢时请等待界面进度和高级日志。
- 离线完整版可以把 `runtime` 目录放在 exe 同级，供网络较差的用户直接使用。
- 不同批次键盘进入下载模式的方式可能不同，工具会给出引导，但仍需要用户按设备实际按键操作。

## 推荐固件包格式

```text
build/flasher_args.json
build/bootloader/bootloader.bin
build/partition_table/partition-table.bin
build/ota_data_initial.bin
build/GK87-Screen.bin
```

工具会递归扫描 zip，不要求这些文件一定在 zip 根目录。
